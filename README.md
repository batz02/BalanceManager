There are 3 different directories:

- `doc`: containing documentation files with the first page `index.html`

- `lib`: containing the `jOpenDocument-1.5.jar` library for exporting to `.ods` files

- `src`: containing all the `.java` files for project development

  

Moreover, inside src there are the following subdirectories:

- `production_files`: containing all `.class` files generated by the compilation with the `javac` command

- `META-INF`: containing the `MANIFEST.MF` file for creating the `.jar` file starting from the `Main-Class`

Also, in the main directory, there is `runner.s`, a script to compile and run the project, executable with the command `bash runner.sh`

Every 90 seconds a Thread triggers the automatic saving of the main table to a .tmp file in a path periodically printed on the terminal
